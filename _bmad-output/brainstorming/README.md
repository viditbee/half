## What it is

**Half** is a second self living in WhatsApp/Telegram — the main's own self, existing outside them. Open source with your own keys; hosted for everyone else.

**Mission:** *"IQ doesn't matter when you have Half."* A leveler, not a power tool — built for the person with **zero** pages, not the quantified-self optimiser.

**The field gap:** every comparable system builds **memory for agents**. Half is **memory about a person, for that person.** Two uncontested grounds follow — a *theory of the recipient* (whether the human can hear it right now) and *person-epistemics* (claims about a person, where contradiction is signal rather than defect).

## The five findings

1. **The core object is the open loop** — not a fact. A fact is true or false; a wanting is *advancing / stalled / abandoned-but-unadmitted / achieved*. Nothing in the field models when a wanting went quiet.
2. **Ingestion is unbounded; belief is bounded.** Keep every byte, never retrieve the corpus. You ingest a corpus and retrieve a *self* — which is why retrieval quality can't degrade with scale.
3. **Trust is the acquisition cost of the only data that matters.** The revealed ledger is free (one OAuth). The stated ledger cannot be ingested, only *told*.
4. **Half's core competence is restraint.** Every system in this field can retrieve. Only Half declines to. The license ladder — `behave → ask → assert`, default `behave` — is the whole design.
5. **The danger of assertion isn't being wrong, it's being unexpected.** A belief may be asserted only if the main already knows Half holds it.
