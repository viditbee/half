- (decision) OQ1 RESOLVED context partitioning: every message is scored against existing strands (loops, people, topics); retrieval weight = strand match x recency x salience; nothing is ever excluded, only down-weighted, satisfying the no-partition law. A topic switch is not a detected event — the weights move. Reply attribution is protected architecturally: the trust economy holds at most 1-2 open questions at a time, so ambiguity is rare by construction
- (decision) OQ2 RESOLVED free-tier economics as a validated MODEL not a finding. Grounded on current pricing (Haiku 4.5 $1/$5 per M, Sonnet 5 $2/$10, Opus 5 $5/$25, Batch API 50%). Heavy free user (20 msg/day, ~8K input/call, ~150 out) ~= $0.18/day ~ $5/mo, which does not survive. Three correctives: prompt caching on the stable prefix (system+constitution+belief set), the bounded belief set keeping that prefix permanently small, and dormancy. Blended estimate $0.50-1.50/month per signup. Free-tier nightly passes run Haiku on the Batch API. Must be instrumented from week one: messages/day, cached fraction, dormancy curve
- (decision) OQ3 RESOLVED confidence semantics: DROP the confidence field. Meaningless for a claim with no truth value and invites false precision. The information already lives in support count, independence count, last-corroborated date, and license
- (decision) OQ4 RESOLVED tension minting cost: never all-pairs. Compare only NEW OR CHANGED entries against the loop set and against beliefs sharing a subject — O(new x loops) not O(n^2) — with a cheap recognition-style filter before any LLM comparison
- (decision) OQ5 RESOLVED quarantine inference: do NOT ship autonomous inference. Detection produces a CANDIDATE and Half asks ('we haven't talked about X in a while — should I leave that alone?'). Gut licenses ask, never assert. Dissolves the precision/recall concern; no empirical validation needed to ship
- (decision) OQ6 RESOLVED crisis mode exit (user accepted): fixed 30-day aftercare floor; licenses restore GRADUALLY rather than snapping back; Half ASKS before resuming the mirror ('is it okay if I start noticing things again?'). Never a silent resumption — that reads as surveillance restarting
- (decision) OQ7 RESOLVED aftercare duration (user accepted): NEVER GATED. Aftercare is part of crisis support, already ungated; caring contacts are cheap (short, infrequent, no ingestion). A lapsed or free user keeps receiving them. Duration follows the evidence base, 1-2 years
- (decision) OQ8 RESOLVED third party at risk (user accepted): Half NEVER runs the crisis protocol on a non-main. It surfaces to its own main ('this message worries me; want the number for a line you could share?') and stops. No contact with the third party, no risk assessment of them, and NO BELIEF RECORDED about them — that would be a verdict about a third party, already banned
